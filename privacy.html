Kebijakan Privasi

RClone Bot hanya dipakai oleh pemilik akun untuk mengunggah file miliknya sendiri ke Google Drive pribadinya.

Aplikasi meminta izin Google Drive terbatas (drive.file), sehingga hanya bisa mengakses file yang dibuat oleh aplikasi ini. Aplikasi tidak membaca file lain di Drive.

Tidak ada data yang dijual, dibagikan ke pihak ketiga, atau dipakai untuk iklan. Token akses disimpan hanya di server milik pemilik akun.

Akses dapat dicabut kapan saja di myaccount.google.com/permissions.
